# Event Participant Manager

## Project Description

Event Participant Manager is a web-based application designed to simplify college event management and participant registration.

Students can view events, register for events, and check their registration details. Administrators can manage registered participants through an admin dashboard.

## Features

### Student Features

- View upcoming events
- View event details
- Register for events
- Register for multiple events
- View registration details
- Responsive design

### Admin Features

- Admin login
- View registered participants
- Search participants
- Delete participants
- View total participant count
- Admin logout

## How to Run

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Open index.html.
4. Right-click on index.html.
5. Select Open with Live Server.
6. The website will open in your browser.
